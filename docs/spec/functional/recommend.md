# RECOMMEND

## Entry points

- Open `Recommend` from the last item in the popup menu or the last `❤️ Recommend` item in the action context menu.

## Store actions

- Open, copy or share the corresponding Chrome Web Store or Firefox Add-ons listing.
- Copy the link when native sharing is unavailable and report copy/share failures.
- Keep these actions independent from support-survey display rules.

## Scope

- Do not promote other extensions or route links through the product website.
